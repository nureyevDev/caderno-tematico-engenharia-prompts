# 🧠 Caderno Temático: Engenharia de Prompts

## 📌 Contexto e Objetivos

Este projeto tem como objetivo explorar o uso da Inteligência Artificial como ferramenta de aprendizagem ativa, utilizando o NotebookLM para organizar e aprofundar conhecimentos sobre **Engenharia de Prompts**.

A Engenharia de Prompts é essencial para obter respostas mais precisas e úteis de modelos de IA como ChatGPT, Gemini e outros.

### 🎯 Objetivos do Projeto

- Entender o conceito de engenharia de prompts
- Aprimorar a interação com modelos de IA
- Criar prompts mais eficientes e reutilizáveis
- Desenvolver pensamento crítico na análise das respostas da IA

## 📘 Miniguia de Estudo

### 🧠 Resumo

A Engenharia de Prompts é o processo de criar instruções claras, objetivas e detalhadas para obter respostas mais eficientes de uma IA.

Boas práticas incluem:
- Ser específico
- Dar contexto
- Definir o formato da resposta
- Solicitar exemplos

---

### 📖 Glossário

| Termo | Definição |
|------|---------|
| Prompt | Instrução enviada para IA |
| LLM | Modelo de linguagem (Large Language Model) |
| Contexto | Informação adicional para melhorar a resposta |
| Output | Resposta gerada pela IA |
| Refinamento | Processo de melhorar o prompt |

---

### 🔁 Prompts Reutilizáveis

- "Explique [tema] de forma simples e com exemplos práticos"
- "Resuma este conteúdo em tópicos claros"
- "Crie um passo a passo sobre [assunto]"
- "Explique como se eu fosse iniciante"
- "Dê exemplos reais sobre [tema]"
